# 用户手册

> 这份是给「打电话的人」看的：怎么拨、怎么打断、设置里每一项干什么、通话记录去哪了。

## 1. 接通一通电话

1. DSH 设置 → **语音通话** → 打开总开关；
2. 点界面上的电话按钮（或按 `Alt+Shift+P`）；
3. 弹出通话窗后，**第一句由你说**——它不会抢话；
4. 点麦克风开始说，说完停下，文字自动发出去；
5. 它一边出字一边念，念完这一句就等你说下一句；
6. 不想聊了点红色挂断键，窗口关闭，通话结束。

> 通话窗是标准窗口：可以拖动、拖角缩放、最小化/最大化、关闭。它始终留在 DSH 页面内，不会弹到系统桌面上。

## 2. 说话、打断、挂断

| 操作 | 结果 |
|---|---|
| 点麦克风 | 开始收音，说完自动发送 |
| 再点一次麦克风 | 结束这一次收音（不是挂电话） |
| 在它说话时开口 | 当前这一轮的话会被打断，你说的新一句优先 |
| 点静音 | 它继续出字，但不出声 |
| 点挂断 | 结束通话，窗口关闭，会话不再续接 |

麦克风按钮只在录音语义下显示「停止录音 / 结束录音」这类字样，不会去抢 DSH 自己的「停止生成」按钮。

## 3. 小窗里都能看到什么

从上到下：

1. **头像** —— 当前模型的圆形形象；
2. **模型名** —— 你面板里选中的那个模型；
3. **对话字幕** —— 它说的话会实时显示在这，也是分句播报的来源；
4. **计费条**（就在麦克风/挂断按钮上方）—— 四组数字：
   - 每秒多少 token（`tok/s`）
   - 这一步一共花了多少 token
   - 缓存命中率
   - 上下文还剩多少（已扣掉本轮 prompt + 输出）
5. **按钮区** —— 麦克风、静音、挂断。

计费条只在通话窗里，不占工作台。

## 4. 设置页「语音通话」

位置：DSH 设置 → 语音通话。分区只负责电话，不动原有设置项。

| 分组 | 你能做什么 |
|---|---|
| 总开关 | 关掉后电话按钮不起作用 |
| 接入 API | 填 TTS 密钥；也可以留空，改用系统里的 `VOLCENGINE_TTS_API_KEY`。想换端点就填自定义地址 |
| 声音设置 | 每个模型一条**下拉**，直接选音色；下面两条**档位条**调语速和音量（拖动即时跟手，停手 260ms 才落盘，不会拖一下就写一次） |
| 模型头像 | 左右箭头逐个切换模型；中间是圆形裁切预览；可以从本地选图，也可以把图片直接拖进预览框 |
| 通话日志 | 开关 + 日志目录。默认 `文档\DSH-AI通话日志`，可以改成你的工作文件夹 |

换头像时：选完图会即时更新，松手后才写入配置；取消选择不会在页面里留下任何临时控件。头像裁切是自动居中的圆形，不满意可以在配置里用 `avatarPos` 微调偏移。

## 5. 每个模型对应什么

默认是「一个模型一套声线 + 一张头像」，用模型名里的关键字匹配，不分档位——DeepSeek 的 Flash / Pro 共用同一条声线、同一张头像。

| 关键字 | 默认音色气质 |
|---|---|
| DeepSeek | 甜美桃子 |
| GPT | 清新女生 |
| Claude | 高冷御姐 |
| Gemini | 邻家女孩 |
| Kimi | 甜美校园 |
| GLM | 柔美女友 |
| 千问 / Qwen | 爽快思思 |

匹配不到时用兜底音色。想换就直接在设置页里下拉选，不用改文件。

## 6. 通话日志

- 每通电话一份 Markdown，文件名 `通话-<callId>.md`；
- 只记两样东西：**说了什么（输入 / 输出）**，以及**什么时候说的（时间）**；
- 默认保存在 `文档\DSH-AI通话日志`，想放到项目里就在设置页把目录改过去；
- 关掉日志开关后不再产生新文件，已有文件不会被删。

## 7. 它和工作台的关系

| 场景 | 行为 |
|---|---|
| 你在输入框写了字还没发 | 电话不会拿它当指令，第一句仍然等你开口 |
| 你在工作台聊天 | 不需要每句都朗读，正常工作台模式 |
| 你在打电话 | 每一句都会念出来 |
| 通话结束 | 内容不会出现在工作台会话里，也不会写回输入框 |

## 8. 常见问题

**问：点了电话没反应？**
看 DSH 设置里总开关是否打开；还不行就去 `http://127.0.0.1:18770/phone/health` 看 `ok` 与 `key`。

**问：它有字但没声音？**
`key:false` 就是 TTS 密钥没读到，去填接入 API。

**问：说了话它不回？**
先看是不是选了一个 DSH 里没配好的模型；再确认日志里有没有「连不上中转」——那是网络问题，换一个档位（比如 DeepSeek）重说一句就行。

**问：头像显示成占位图形？**
说明这个模型还没配头像。去设置页切到该模型，上传一张图即可。

**问：能同时装两份吗？**
不能。端口、配置、头像目录、样式都与 `dsh-ai-phone` 同名共用，装第二份必须先把这些全部隔离。
